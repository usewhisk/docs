---
title: Fees
description: Fetch CCTP V2 fee tiers from Iris and compute the protocol fee, forwarder fee and maxFee for a burn, in USDC subunits.
---

A CCTP V2 burn pays two fees out of the burned amount: Circle's protocol fee, a rate on the amount, and, when Circle's relayer mints, a flat forwarder fee. The burn caps both with `maxFee`.

```ts
import {
  Base,
  Ethereum,
  getBurnFees,
  pickFeeTier,
  pickForwarderFee,
  computeMaxFee,
} from "@usewhisk/cctp";

const tiers = await getBurnFees(
  "mainnet",
  Base.cctpDomain,
  Ethereum.cctpDomain,
);
const fast = pickFeeTier(tiers, "fast");

console.log(
  fast.finalityThreshold,
  fast.minimumFee,
  pickForwarderFee(fast, "high"),
);

const { burnFee, forwarderFee, maxFee } = computeMaxFee({
  amount: 250_000_000n,
  tier: fast,
  forwarderLevel: "med",
  burnFeeBufferBps: 1_000,
});
console.log(burnFee, forwarderFee, maxFee);
```

Circle deducts the fees it actually executes, which can be less than `maxFee`. The recipient gets at least `amount - maxFee`. For how Whisk's engine turns this into a quote the payer sees, and who bears the fee, see [quotes and fees](/concepts/quotes-and-fees).

## Units

| Value                                              | Unit                                  | Example                                     |
| -------------------------------------------------- | ------------------------------------- | ------------------------------------------- |
| Amounts, `burnFee`, `forwarderFee`, `maxFee`       | USDC subunits, 6 decimals, `bigint`   | `250_000_000n` is 250 USDC                  |
| `BurnFeeTier.minimumFee`                           | Hundredths of a basis point, `bigint` | Iris's `1.3` bps is `130n`, which is 0.013% |
| Buffers (`burnFeeBufferBps`, `forwarderBufferBps`) | Whole basis points, `number`          | `1_000` is 10%                              |

Every step rounds up, because a `maxFee` one subunit short of the Fast fee turns a Fast transfer into a Standard one.

## Finality thresholds

| Export              | Value  |                                                                   |
| ------------------- | ------ | ----------------------------------------------------------------- |
| `FINALITY_FAST`     | `1000` | Attested after a block or two, before hard finality. Costs a fee. |
| `FINALITY_STANDARD` | `2000` | Attested after hard finality. Cheaper than Fast.                  |

`FinalityThreshold` is `1000 | 2000`. `TransferSpeed` is `"fast" | "standard"`, the name the helpers take.

## `getBurnFees`

`getBurnFees(network, sourceDomain, destinationDomain, options?): Promise<BurnFeeTier[]>`

Reads `GET /v2/burn/USDC/fees/{src}/{dst}` from Iris, with `?forward=true` unless you turn it off. Returns one `BurnFeeTier` per finality Iris offers on the route; rows for other thresholds are dropped.

<ParamField path="network" type='"mainnet" | "testnet"' required>
  The source chain's `network`.
</ParamField>
<ParamField path="sourceDomain" type="number" required>
  The source chain's `cctpDomain`.
</ParamField>
<ParamField path="destinationDomain" type="number" required>
  The destination chain's `cctpDomain`.
</ParamField>
<ParamField path="options.includeForwarderFee" type="boolean">
  Defaults to `true`. Set `false` when the burn will not use Circle's forwarder,
  for example to Stellar, Starknet or any chain whose `forwardingDestination` is
  false.
</ParamField>

`GetBurnFeesOptions` also takes the Iris [request options](/reference/cctp/iris#request-options) (`timeoutMs`, `maxRetries`, `baseDelayMs`, `signal`, `fetch`, `limiter`).

### `BurnFeeTier`

<ResponseField name="finalityThreshold" type="1000 | 2000">
  Which speed this row prices.
</ResponseField>
<ResponseField name="minimumFee" type="bigint">
  The protocol fee rate, in hundredths of a basis point.
</ResponseField>
<ResponseField name="forwardFee" type="ForwarderFeeTier">
  Present when fetched with `includeForwarderFee`. `{ low, med, high }`, each
  a flat fee in USDC subunits. Circle recommends `med` or higher; `high`
  already carries a buffer.
</ResponseField>

## `pickFeeTier`

`pickFeeTier(tiers: readonly BurnFeeTier[], speed: TransferSpeed): BurnFeeTier`

The row for `"fast"` or `"standard"`. Throws `ProtocolError("tier_not_found")` when Iris returned none for that speed on this route. Check the source's `capabilities.fastSource` before offering Fast.

## `pickForwarderFee`

`pickForwarderFee(tier: BurnFeeTier, level?: "low" | "med" | "high"): bigint`

The forwarder fee at `level` (default `"med"`), in USDC subunits. Throws `ProtocolError("fee_unavailable")` if the tier was fetched without forwarder fees. `selectForwarderFee` is the same function under its fee-maths name.

## `computeMaxFee`

`computeMaxFee(input: ComputeMaxFeeInput): ComputeMaxFeeResult`

```text
burnFee      = max(ceil(amount × minimumFee / 1,000,000), minBurnFee)
forwarderFee = ceil(forwardFee[level] × (10,000 + forwarderBufferBps) / 10,000)
maxFee       = ceil(burnFee × (10,000 + burnFeeBufferBps) / 10,000) + forwarderFee
```

`buildBurnIntent` calls this for you unless you pass `fee.maxFee`.

<ParamField path="amount" type="bigint" required>
  The burn amount in USDC subunits.
</ParamField>
<ParamField path="tier" type="BurnFeeTier" required>
  From `pickFeeTier`.
</ParamField>
<ParamField path="forwarderLevel" type='"low" | "med" | "high"'>
  Defaults to `"med"`.
</ParamField>
<ParamField path="includeForwarder" type="boolean">
  Defaults to `true`. Set `false` for a burn without the forwarder; then
  `forwarderFee` is `0n` and the tier needs no `forwardFee`.
</ParamField>
<ParamField path="forwarderBufferBps" type="number">
  Whole basis points added to the forwarder fee, 0 to 10,000. Defaults to `0`.
</ParamField>
<ParamField path="burnFeeBufferBps" type="number">
  Whole basis points added to the protocol fee inside `maxFee` only. Circle
  takes the fee it executes, so this raises the ceiling, not the charge.
  Defaults to `0`. Whisk's engine uses `1_000` (10%) on Fast burns, so a rate
  change between quote and burn does not drop the transfer to Standard.
</ParamField>
<ParamField path="minBurnFee" type="bigint">
  The on-chain minimum from [`getStandardMinFee`](#getstandardminfee), in USDC
  subunits. The protocol fee is raised to it if lower. Defaults to `0n`.
</ParamField>

Returns `{ burnFee, forwarderFee, maxFee }`, all `bigint` subunits. `burnFee` is before any buffer; `forwarderFee` includes its buffer. A negative amount or buffer throws `InvalidInputError`.

## `getStandardMinFee`

`getStandardMinFee(chain: EvmChain, amount: bigint, options?: GetStandardMinFeeOptions): Promise<bigint>`

On chains with `capabilities.standardFeeSwitch`, `TokenMessengerV2.getMinFeeAmount(amount)` sets the least `maxFee` a Standard burn may carry, which can be more than Iris quotes. This reads it over JSON-RPC, in USDC subunits. Pass it to `computeMaxFee` as `minBurnFee`. On other chains the contract call reverts, so the function throws `InvalidInputError("invalid_chain")` without calling. `GetStandardMinFeeOptions` is `RpcOptions` (`rpcUrls`, `fetch`).

```ts
import {
  Monad,
  Ethereum,
  getBurnFees,
  pickFeeTier,
  getStandardMinFee,
  computeMaxFee,
  buildBurnIntent,
} from "@usewhisk/cctp";

const amount = 1_000_000_000n;
const tier = pickFeeTier(
  await getBurnFees("mainnet", Monad.cctpDomain, Ethereum.cctpDomain),
  "standard",
);

const minBurnFee = Monad.capabilities.standardFeeSwitch
  ? await getStandardMinFee(Monad, amount)
  : 0n;

const fees = computeMaxFee({ amount, tier, minBurnFee });

const intent = buildBurnIntent({
  source: Monad,
  destination: Ethereum,
  amount,
  mintRecipient: "0x4f2a1c7e9b3d5a8f6e0c2b4d7a9f1e3c5b8d0a2e",
  fee: { tier, maxFee: fees.maxFee },
});
```

## Lower level helpers

```ts
import {
  computeBurnFee,
  parseFeeBps,
  parseForwarderFee,
  selectForwarderFee,
  FINALITY_FAST,
  type BurnFeeTier,
} from "@usewhisk/cctp";

const tier: BurnFeeTier = {
  finalityThreshold: FINALITY_FAST,
  minimumFee: parseFeeBps(1.3),
  forwardFee: {
    low: parseForwarderFee(150_000),
    med: parseForwarderFee(200_000),
    high: parseForwarderFee(300_000),
  },
};

console.log(computeBurnFee(25_000_000n, tier.minimumFee));
console.log(selectForwarderFee(tier, "med"));
```

| Function                              |                                                                                                                            |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `computeBurnFee(amount, feeCentiBps)` | `ceil(amount × feeCentiBps / 1,000,000)`. 25 USDC at 1.3 bps is `3250n` (0.00325 USDC).                                    |
| `parseFeeBps(raw)`                    | An Iris `minimumFee` (number or string) to hundredths of a basis point, rounded up. Exponent forms throw `IrisParseError`. |
| `parseForwarderFee(raw)`              | An Iris forwarder fee to a `bigint` of subunits, rounded up.                                                               |
| `selectForwarderFee(tier, level?)`    | Same as `pickForwarderFee`.                                                                                                |

## Upfront fees

On chains with `capabilities.upfrontFeeSource`, the Fast and forwarding fees can instead be paid on top of the amount from a signed Iris quote, so the recipient gets the whole amount. See [`getSignedBurnQuote`](/reference/cctp/iris#signed-upfront-fee-quotes) and [`buildBurnWithFeesIntent`](/reference/cctp/builders#buildburnwithfeesintent).
